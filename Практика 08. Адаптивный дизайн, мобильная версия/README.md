# Практическая работа № 8. Дизайн с учётом современных тенденций

Цвета и шрифты заданы переменными в `app/static/css/style.css`: бумажный фон, тёмно-зелёный основной цвет, терракотовый акцент.
Заголовки шрифтом с засечками (Georgia), текст системным шрифтом без загрузки из интернета.

## Тенденции, которые использованы

- минимализм: один основной цвет, много свободного места, без рамок и теней там, где они не нужны;
- карточный дизайн: мероприятия и заявки на телефоне показаны карточками;
- микро-взаимодействия: карточка приподнимается при наведении, кнопки нажимаются, поля подсвечиваются при вводе,
  страница плавно появляется. Для тех, кто отключил анимацию в системе, всё это выключается (`prefers-reduced-motion`).

## Мобильная версия 390×844

- сетка карточек: 3 колонки, на планшете 2, на телефоне 1 (`@media`);
- меню превращается в кнопку-«бургер» (`static/js/nav.js`);
- таблицы заявок на телефоне становятся карточками, подписи полей берутся из `data-label`;
- размер шрифта в полях 16 px, чтобы телефон не увеличивал страницу при вводе.

## Графика

Фото с pexels.com (номера в `docs/photo_sources.md`), обрезаны до 800×500 и сжаты в JPEG:
главное фото 89 КБ, карточки от 34 до 79 КБ. Для карточек добавлен `loading="lazy"`.

## Файлы .html для мобильной версии

В папке `mobile/` три страницы, сохранённые с работающего сайта: `index.html`, `register.html`, `requests.html`.
Они подключают стили и картинки из `app/static` и открываются без сервера.

## Скриншоты

- `1`-`3` компьютер (окно Chrome);
- `4`-`8` телефон 390×844 (режим устройства в Chrome): главная, меню, мероприятие, регистрация, заявки;
- `9_файл_mobile_*.png` те же страницы, открытые из файлов папки `mobile`.
