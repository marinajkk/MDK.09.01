# Практическая работа № 3. Разработка модулей ИС в соответствии с ТЗ

Портал «Конференции.РФ». Бэкенд на Python (Flask, SQLite), фронтенд на шаблонах Jinja, HTML и CSS.

## Структура проекта

- `app/` код приложения: `db.py` (класс Database), `models.py` (классы UserRepository, EventRepository, RequestRepository),
  `validators.py` (проверка форм), `auth.py`, `main.py`, `admin.py` (маршруты)
- `app/templates/`, `app/static/` фронтенд
- `schema.sql` таблицы базы данных
- `tests/` проверки модулей

## Что сделано

| Модуль | Где | Скриншот |
|---|---|---|
| Регистрация: логин уникальный, пароль от 8 символов, телефон и почта по формату | `validators.py`, `auth.py` | `2_регистрация_ошибки.png`, `3_после_регистрации.png` |
| Авторизация | `auth.py` | `3_после_регистрации.png` |
| Создание заявки | `main.py`, `new_request.html` | `4_создание_заявки.png` |
| Просмотр своих заявок | `my_requests.html` | `5_мои_заявки.png` |
| Панель администратора | `admin.py`, `admin.html` | `6_админ_запрещено.png`, `7_панель_администратора.png` |

Пароли хранятся в виде хеша (`generate_password_hash`). Работа с базой собрана в классах, маршруты вызывают только их методы.

## Проверка

Десять тестов в `tests/test_modules.py`: регистрация, повтор логина, короткий пароль, неверный телефон и почта, вход, создание заявки,
доступ к панели администратора. Результат на скриншоте `8_тесты.png`.
