# Конференции.РФ

Учебный портал для подачи заявок на конференции, форумы и семинары. МДК.09.01 «Проектирование и разработка веб-приложений».
Выполнила Хачатрян Марине Артаковна, группа 4ИСП9-45.

Роли: гость (смотрит мероприятия, регистрируется), участник (подаёт заявки, следит за статусом, оставляет отзыв после завершения),
администратор (видит все заявки, фильтрует, меняет статусы). Статусы заявки: новая → назначено → завершено.

Стек: Python 3, Flask, SQLite, шаблоны Jinja, HTML, CSS, JavaScript.

## Запуск

```
pip install -r requirements.txt
python run.py create-admin admin Admin2026!
python run.py
```

Сайт открывается на http://localhost:5000. Вход администратора: логин `admin`, пароль `Admin2026!` (тестовые данные).
Тесты: `python -m pytest`.
