# Практическая работа № 9. Улучшение форм и интерфейса

| Пункт задания | Что сделано | Где | Скриншот |
|---|---|---|---|
| Ошибки валидации на странице | `static/js/forms.js` проверяет поля при уходе из поля и при отправке и пишет сообщение под полем; сервер проверяет всё ещё раз | `register.html`, `login.html`, `new_request.html`, `review.html` | `1`, `2`, `7` |
| Выпадающие списки | помещение и способ оплаты выбираются из списков; сервер принимает только значения из `ROOMS` и `PAYMENTS` в `validators.py` | `new_request.html` | `3` |

поэтому форму нельзя обойти отключением JavaScript.
