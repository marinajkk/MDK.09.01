## Ошибки, найденные при проверке

1. Если в настройках не было `SECRET_KEY`, приложение падало при открытии любой страницы с формой: у Flask ключ по умолчанию `None`,
   а проверка искала только наличие поля. Теперь проверяется значение.
2. Токен CSRF с русскими буквами давал ошибку 500 вместо 400: `compare_digest` не принимает строки не из ASCII.
   Теперь сравниваются байты.
3. Запрос без токена пропускался, если в сессии токена ещё не было (пустая строка равна пустой строке). Теперь такой запрос отклоняется.

Каждая ошибка закрыта тестом в `tests/test_security.py`. Всего 24 теста, результат на `8_тесты.png`.
